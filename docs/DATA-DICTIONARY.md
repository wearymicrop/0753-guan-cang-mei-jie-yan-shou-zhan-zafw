# 数据字典

输入顶层 `batch` 为批次号，`at` 为带偏移的验收截止时间。还需提供四个记录数组。表内数据行号从 1 起算。报告保留行号及原记录，支持用相同输入重算。

| 数组 | 字段 | 规则 |
|---|---|---|
| `catalogs` | `version`、`start`、`end`、`tiers` | 策略使用半开有效期，唯一生效版本须声明 `online`、`vault` 两层。 |
| `objects` | `object_id`、`path`、`bytes`、`sha256` | 馆号为字符串。字节数输入为整数，输出为十进制字符串。摘要为 64 位十六进制文本。 |
| `routes` | `version`、`tier`、`from_prefix`、`to_prefix`、`start`、`end` | 先选生效版本，再选最长完整目录前缀。空源前缀匹配根目录。多个不同目标或同层目标路径被多原件占用时隔离。 |
| `replicas` | `tier`、`path`、`data_b64`、`observed` | 载荷为 Base64，实际解码后计算大小与 SHA-256。按层级和路径取截止前最后一秒观测，同秒冲突保留全部行。 |

路径转 Unicode NFC 和斜线分隔，去掉多余的斜线及点段。保留大小写和合法空格。拒绝绝对路径、上级路径和控制字符。以馆号去重，同馆号的归一化路径、字节及摘要都相等才视为重传。没有馆号的输入行单独隔离，无法对应原件账。

当两层实测都匹配时，原件为两副本齐全。至少一层缺失且没有冲突时为待补。任何清单、映射或字节冲突均优先进冲突。已恢复的历史漂移作为证据。对账状态反映分类完整性，冲突和待补数量单独展示。
